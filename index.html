01

Mechanism

four parts, one forward pass

CMATS cross-modal attention token selection

Visual patches and text tokens are scored by bidirectional cross-modal attention, and the top 30% of each modality survive into the local branch. Selection is a ranking rather than a threshold, so it holds whatever the length of the description.

GLAW loss agreement-weighted dual TAL

A global branch and the token-selected local branch are optimised together. Each branch carries a weight from the sigmoid of its own image–text agreement score, so a reliable pair drives the gradient while an unreliable one steps back — the trade-off is per pair, not a fixed hyperparameter.

FDR feature denoising regularisation

Gaussian noise (σ = 0.1) is injected into the bypass features during training, and the cosine similarities of the noisy and clean features are matched with an MSE term — flattening the similarity landscape around each identity.

Centroid loss EMA identity centres

Class centroids, updated by exponential moving average from clean samples only, pull each feature toward its identity centre, weighted by the same agreement score.

03

Run it

CLIP ViT-B/16 · 60 epochs

# train, RSTPReid
pip install -r requirements.txt

python train.py \
  --name GLAW --dataset_name RSTPReid --loss_names glaw \
  --num_epoch 60 --batch_size 64 --lr 5e-6 \
  --temperature 0.02 --tau 0.015 --margin 0.1 \
  --select_ratio 0.3 --cm_alpha 0.5 \
  --fdr_weight 1.0 --noise_std 0.1 \
  --centroid_weight 0.5 --centroid_momentum 0.99 \
  --img_aug --txt_aug --root_dir data

# evaluate the best checkpoint
python test.py \
  --config_file logs/RSTPReid/<run>/configs.yaml
  • Backbone OpenAI CLIP ViT-B/16; weights are fetched by the clip package on first use.
  • Data Place the datasets under data/ as described in the README; images at 384 × 128, annotations read from each dataset's JSON.
  • Eval Every epoch writes configs.yaml next to the checkpoints, which test.py reads directly.
